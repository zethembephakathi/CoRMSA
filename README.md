# CoRMSA Website and Android Application

## Project Overview

The CoRMSA Website and Android Application was developed as part of a Work Integrated Learning (WIL) programme for the Consortium for Refugees and Migrants in South Africa (CoRMSA).

CoRMSA is a nonprofit organisation focused on promoting and protecting the rights of asylum seekers, refugees and migrants.

The project involved developing a website to present the organisation's background, mission, vision, services and activities, alongside an Android application.

## My Role and Responsibilities

**Role: Team Leader**

I coordinated a six-member team, delegated tasks, monitored progress and supported collaboration throughout the project. I also worked with another team member on the Android application while other team members worked on the website.

## Website Features

The website included the following sections:

* Home
* About Us
* Gallery
* Services
* Blog
* Contact
* Social media links

## Android Application

The Android application was developed using Java and Android Studio.

The repository contains source files associated with the following components:

* Login and registration
* Appointments
* Donations and payments
* Permit applications
* Accommodation applications

These components are described according to the available source files; their complete functionality should be verified against the application code.
